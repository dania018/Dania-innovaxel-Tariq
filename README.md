Dania Tariq - URL Shortener - Innovaxel Assessment
This is a backend project to shorten URLs and retrieve statistics.

Tech Stack
Node.js
Express.js
MongoDB
React (minimal frontend) for:
Creating short URL
Retrieving & redirecting original URL
Thunder Client / Postman
Used validator library for URL validation
Instructions
Clone the repo
git clone https://github.com/dania018/Dania-innovaxel-Tariq.git

Checkout dev branch
git checkout dev

Install dependencies
npm install

Start server
cd url-short-server && node index.js

For frontend
cd url-short-client && npm run dev
